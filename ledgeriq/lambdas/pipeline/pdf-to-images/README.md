# pdf-to-images

![Runtime](https://img.shields.io/badge/Runtime-Python%203.11-3776AB?logo=python)
![Step](https://img.shields.io/badge/Step-2%20Convert-orange)
![Library](https://img.shields.io/badge/Library-pdf2image-green)

Converts PDF pages to PNG images at 300 DPI for OCR processing. Uploads each page image to S3 and returns list of S3 keys for parallel OCR execution.
