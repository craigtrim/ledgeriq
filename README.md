# LedgerIQ

LedgerIQ automates receipt data extraction and expenditure analysis by ingesting multi-format receipt images, applying vision-based LLMs for structured data extraction into normalized line-item representations, and executing autonomous price benchmarking against real-time market data to identify purchasing inefficiencies and provide spend analytics with statistically-grounded price variance assessments.

## Installation

```bash
poetry install
```

## Usage

```bash
poetry run python -m ledgeriq
```

## Development

This project uses Poetry for dependency management and Python 3.11+.
